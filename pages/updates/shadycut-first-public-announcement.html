ShadyCut — First Public Announcement

After the last couple of months of building ShadyCut privately, this is the first proper public introduction.

Published
Sep 21, 2026
Reading time
—

ShadyCut is an AI-assisted editing system built to turn long gaming streams into story-driven videos.

In the video, I walk through what ShadyCut does today, including:

  • how it analyzes long recordings,
  • how it looks for the strongest story inside a session,
  • the Story Blueprint and Director’s Plan,
  • how the selected footage becomes an editable first cut,
  • feedback from one of the creators whose footage I used during development,
  • and where the project is currently heading.

The goal is not to create a locked AI-generated final video.

ShadyCut is designed to remove the repetitive work that happens before and during the first cut, while keeping the creator or editor in control of the final result.

The AI should remove work. It should not remove personality.

Where things are now

ShadyCut is working, but it is still early.

The current focus is improving how deeply the system understands what actually happens inside long gaming sessions.

That means better game-specific understanding, stronger use of gameplay and speech together, and more reliable evidence for the story and Director.

I am continuing to run more real footage through the system, find what breaks, and improve it from there.

This is the first public announcement.

There is still a lot to build, but ShadyCut is now at the point where I can finally start showing the work properly.
